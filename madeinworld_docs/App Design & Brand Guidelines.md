### **App Design & Brand Guidelines**

**1.0 Core Visual Identity**

This document outlines the design system and brand identity for the application. The primary goal is to create a user interface that projects a **premium, trustworthy, and modern** brand identity. All UI/UX components and screens must strictly adhere to these guidelines to ensure a cohesive and high-quality user experience.

**1.1 Design Philosophy**

Our visual language is guided by the following principles:

* **Keywords:** Premium, Sophisticated, Global, Trustworthy, Tech-Forward, Clean, Efficient.  
* **Inspiration:** The design philosophy merges the functional density and efficiency of leading super-apps (e.g., Meituan) with a unique and sophisticated aesthetic derived from the "Made in World" brand identity.

**2.0 Color Palette**

The color palette is intentionally minimal and clean, built around a dominant, attractive red to guide user attention and action. The application must support both a **Light Mode** and a **Dark Mode**.

* **Theme Red:** The primary action color.  
  * **Usage:** Call-to-action buttons, active UI states (tabs, inputs), important prices, and key highlights.  
* **Light Red Background:** A subtle accent color.  
  * **Usage:** Backgrounds for secondary elements requiring gentle emphasis, such as the store selector button.  
* **Primary Blue:** A corporate branding accent.  
  * **Usage:** To be used sparingly for specific brand elements or secondary module icons where clear differentiation from the primary red is needed.  
* **Light Background:** The default canvas color.  
  * **Usage:** The main background for all application screens in Light Mode.  
* **Primary Text:** The standard text color.  
  * **Usage:** All headings and primary body content.  
* **Secondary Text:** For de-emphasized text.  
  * **Usage:** Supporting information, captions, and strikethrough prices.

**3.0 Typography**

Typography is a cornerstone of our clean and efficient UI. We use a combination of font families to ensure excellent readability and a consistent modern aesthetic across all supported languages.

* **Primary Font (Latin Characters):** **Manrope**  
  * This font must be used for all English and other non-Chinese text within the application.  
* **Primary Font (Chinese Characters):** **Source Han Sans SC (思源黑体SC)**  
  * **Rationale:** Source Han Sans is selected for its elegant, minimalistic, and simple aesthetic, which pairs harmoniously with Manrope. It is optimized for screen readability and offers a wide range of weights, ensuring a consistent and high-quality typographic experience for Chinese text.  
* **Typographic Hierarchy:**  
  * **Headings** (e.g., "热门推荐"): Use **Manrope Bold** or **Extrabold** / **Source Han Sans Bold** or **Heavy**.  
  * **Module/Card Titles:** Use **Manrope Semibold** / **Source Han Sans Medium**.  
  * **Body Text:** Use **Manrope Regular** / **Source Han Sans Regular**.

**4.0 Component Library**

The following specifications define the base styles for our core UI components.

* **Buttons (Call-to-Action)**  
  * **Background:** Theme Red  
  * **Text:** White  
  * **Shape:** Rounded corners (approx. 10px radius)  
* **Cards**  
  * **Usage:** Containers for modules, products, and other grouped content.  
  * **Background:** White  
  * **Shape:** Rounded corners (approx. 12px to 16px radius)  
  * **Elevation:** A subtle drop shadow must be applied to create depth and separate the card from the Light Background.  
* **Input Fields**  
  * **Default State:** Clean design with rounded corners and a subtle border.  
  * **Active State:** When a user selects the input field, the border must be highlighted with Theme Red to provide clear visual feedback.
